## [1.0.0] - 2026-09-04

### Added

- Portable explicit-only Agent Skill for bounded pull-request and merge-request improvement.
- Awesome Contract, green/yellow/red risk lanes, and evidence-driven convergence rules.
- Adversarial general and specialist review with disclosed independence levels.
- Mandatory UI Experience Gate for UX, visual quality, responsiveness, and accessibility.
- Exact-source-commit protection, repository-gate enforcement, and post-merge verification.
- Provider-neutral guidance for GitHub, GitLab, Bitbucket, and Azure DevOps.
- Dependency-free validation, safe Codex and Claude Code installation, and adversarial eval suites.
