# Changelog

All notable changes to this project will be documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Made visual evidence inspection and reusable real-app verification recipes explicit, including conditional 3D/game checks.
- Scoped test execution to affected behavior and required gates, reusing current evidence instead of repeating unchanged suites.
- Added the Awesome Face as the project brand mark with complete CC BY-SA 3.0 attribution and source-integrity validation.
- Replaced the wide README flowchart with a mobile-friendly workflow summary.

## [1.0.0] - 2026-09-04

### Added

- Portable explicit-only Agent Skill for bounded pull-request and merge-request improvement.
- Awesome Contract, green/yellow/red risk lanes, and evidence-driven convergence rules.
- Adversarial general and specialist review with disclosed independence levels.
- Mandatory UI Experience Gate for UX, visual quality, responsiveness, and accessibility.
- Exact-source-commit protection, repository-gate enforcement, and post-merge verification.
- Provider-neutral guidance for GitHub, GitLab, Bitbucket, and Azure DevOps.
- Dependency-free validation, safe Codex and Claude Code installation, and adversarial eval suites.
